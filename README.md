# Souped Up 2026

ระบบเดโมสำหรับสมัครสมาชิก ลงทะเบียนนักแข่ง และซื้อบัตร **Souped Up VIP Village 2026** รองรับภาษาไทย/อังกฤษ ทำงานด้วย HTML, CSS และ JavaScript โดยไม่ต้อง build

- **Live:** https://nidss.github.io/su/
- **VIP standalone:** https://nidss.github.io/suvip/

> Auth, payment, profile และ Dashboard เป็น mock data สำหรับสาธิต ไม่มี backend หรือการชำระเงินจริง

## Flow หลัก

หน้าเข้าสู่ระบบมีบัญชีตัวอย่าง 3 แบบ:

- **ผู้ใช้ใหม่** — ยังไม่มีข้อมูลส่วนตัว นักแข่ง หรือ VIP
- **ผู้ใช้เดิม** — มีข้อมูลบุคคล/นิติบุคคล บัญชีคืนเงิน และนักแข่งพร้อมแล้ว (แท็บ VIP แสดงยังไม่มีการซื้อบัตร)
- **ผู้ใช้ที่ซื้อบัตร VIP** — สมัครแล้วไปซื้อบัตรเลย ไม่มีข้อมูลส่วนตัว มีเฉพาะประวัติการซื้อบัตร VIP

หลังสมัครหรือเข้าสู่ระบบด้วยบัญชีที่ยังไม่มีข้อมูล ระบบจะแสดงหน้า **คุณต้องการทำอะไร?** ให้เลือกเส้นทางก่อน:

- **ลงทะเบียนนักแข่ง** → กรอกข้อมูลส่วนตัวและเลือกบัญชีคืนเงินมัดจำแบบไทย/ต่างประเทศ → ข้อตกลง → wizard นักแข่ง
- **ซื้อบัตร VIP Village** → หน้าซื้อบัตร VIP โดยใช้ข้อมูลบัญชีสมาชิกที่เข้าสู่ระบบ

หน้าเลือกเส้นทางเปิดใช้งานผ่าน flag `CHOOSE_ENABLED=true`
หน้าซื้อบัตรไม่มีทางลัดจากหน้าเข้าสู่ระบบ ผู้ใช้ต้องสมัครสมาชิกหรือเข้าสู่ระบบก่อนเสมอ

## ลงทะเบียนนักแข่ง

Stepper ไม่มีเลขนำหน้าและประกอบด้วย 6 ขั้น:

1. ข้อตกลง
2. นักแข่ง
3. ที่จอดรถ
4. สรุปยอด
5. ชำระเงิน
6. สำเร็จ

ฟอร์มปัจจุบันลงทะเบียนนักแข่ง 1 คนและ 1 รุ่นการแข่งขัน ปุ่มเพิ่มนักแข่ง/เพิ่มรุ่นถูกซ่อน ประเภทผู้สมัครเลือกจาก dropdown ในหน้าข้อมูลส่วนตัวได้เพียงประเภทเดียวต่อผู้สมัคร หน้า **ชำระเงินสำเร็จ** แสดงข้อมูลชุดเดียวกับใบเสร็จบนหน้าจอ (ข้อมูลผู้ชำระเงิน + ตารางรายการต่อคัน: ชื่อนักแข่ง เบอร์รถ รุ่น ค่าสมัคร ค่ามัดจำ รวม/คัน + ยอดรวม)

บัญชีคืนเงินมัดจำในหน้าข้อมูลส่วนตัวมี dropdown ให้เลือกบัญชีธนาคารไทยหรือบัญชีต่างประเทศก่อนแสดงช่องกรอก เช่นเดียวกับบัญชีรับเงินรางวัล ในขั้น **นักแข่ง** บัญชีรับเงินรางวัลอยู่ต่อจากส่วนอัปโหลดรูป โดยชื่อ/นามสกุลดึงจากข้อมูลนักแข่งและแก้ไขไม่ได้ ในขั้น **ที่จอดรถ** พีทเรียงเลข 1–148 โดยเต็นท์ 12 มีพีท 41–42 และเต็นท์ 13 มีพีท 43–44 แต่ยังคงความกว้างเท่าเต็นท์ 4 พีท ช่องที่จองแล้วแสดงข้อมูลผู้จองแบบไม่มีรูปเมื่อชี้เมาส์ และยังกดเพื่อเปิดรายละเอียดได้ หน้าสรุปยอดเริ่มนับถอยหลังชำระเงิน 2 ชั่วโมง และหน้าสำเร็จ/ใบเสร็จนักแข่งไม่มี QR

Pricing: ค่าสมัคร 7,000 บาท + ค่ามัดจำ 10,000 บาท = **17,000 บาทต่อคัน**

## ซื้อบัตร VIP Village

หน้า `vip.html` ใช้ UI จากโปรเจกต์ `suvip` และไม่มีส่วนข้อมูลผู้สมัคร

- เลือก Early Bird หรือ Normal Price
- วันเข้างาน 4–6 ธันวาคม 2026
- แพ็กเกจ 3 วันเลือกไม่ได้เมื่อมีวันที่เต็ม
- เลือกมีรถ/ไม่มีรถ; ถ้ามีรถต้องกรอกทะเบียน
- เลือกไซส์เสื้อและข้อมูลอาหารบุฟเฟต์แยกต่อบัตร
- กด **+ เพิ่มบัตรเข้างาน** เพื่อสร้างบัตรใบที่ 2 เป็นต้นไป
- กล่องบัตร collapse/expand ได้เมื่อมีหลายใบ
- Flow: กรอกข้อมูล/เลือกแพ็กเกจ → **สรุปการชำระเงิน** → **ชำระเงิน** → สำเร็จ
- หน้า **สรุปการชำระเงิน** รวมยอดชำระ เงื่อนไขการชำระเงิน และ checkbox ออกใบกำกับภาษี ส่วนหน้า **ชำระเงิน** เหลือเฉพาะการเลือกวิธีชำระเงิน
- ใบเสร็จบัตร VIP แสดงทะเบียนรถในส่วนสรุปรายการ (ไม่มีทะเบียนแสดงเป็น `-`)

หน้าซื้อบัตรเวอร์ชัน standalone ถูก sync ไปที่ [nidss/suvip](https://github.com/nidss/suvip)

## หน้าโปรไฟล์ (ยินดีต้อนรับกลับ)

หน้าโปรไฟล์แยกตามประเภทผู้ใช้:

- **ผู้ใช้ที่มีข้อมูลส่วนตัว (ลงทะเบียนนักแข่ง)** — มี 4 แท็บ: ข้อมูลส่วนตัว, ข้อมูลนักแข่ง, VIP Village (แสดงยังไม่มีการซื้อบัตร), ประวัติการลงทะเบียน
- **ผู้ใช้ที่ซื้อบัตร VIP อย่างเดียว** — ไม่มีแท็บ มี 2 กล่อง คือ บัญชีผู้ใช้ และ ประวัติการซื้อบัตร VIP Village

รายละเอียดอื่น ๆ:

- กล่องบัญชีผู้ใช้แสดง ชื่อผู้ใช้ / อีเมล / รหัสผ่าน (+ เปลี่ยนรหัสผ่าน)
- การ์ดบัตร VIP แสดงทะเบียนรถ (ไม่มีแสดงเป็น `-`)
- รองรับบุคคลธรรมดาและนิติบุคคล, Line เป็นข้อมูลบังคับ, ไม่มีวัน/เดือน/ปีเกิดและที่อยู่จัดส่ง
- บัญชีคืนเงินมัดจำอยู่ในข้อมูลส่วนตัวและไม่แสดงสำหรับเส้นทาง VIP
- ประวัติการลงทะเบียนและ VIP Village เปิดใบเสร็จผ่าน modal ได้

## Dashboard ผู้ดูแล

เปิดด้วย `Ctrl + Shift + Z`

- กลุ่ม **ข้อมูลผู้สมัคร, นักแข่ง** และ **ข้อมูลผู้ซื้อบัตร VIP Village**
- แท็บ **ข้อมูลผู้สมัคร** แยกเป็น **บุคคลธรรมดา** และ **นิติบุคคล** แต่ละแถวมีคอลัมน์บัญชีคืนเงินมัดจำ (ธนาคาร/เลขที่บัญชี/ชื่อบัญชี) และขยาย/ยุบเพื่อดูนักแข่งที่อยู่ภายใต้ผู้สมัครได้ (เต็นท์/พีท)
- แท็บ **ข้อมูลนักแข่ง** มีคอลัมน์ `ชื่อ-นามสกุลผู้สมัคร`, `เลขเต็นท์` และ `เลขพีท` เพิ่มขึ้น และตัดคอลัมน์ `ที่อยู่ตามบัตรฯ` กับ `รถยนต์ รุ่น/รหัสเครื่อง` ออก
- แท็บ **ข้อมูลผู้ซื้อบัตร VIP** มีพายชาร์ต (Chart.js doughnut) ในการ์ด KPI ใบแรก สรุปจำนวนบัตรที่ขายได้แยกตามวัน (4/5/6 ธ.ค.) และตารางแสดงคอลัมน์รายวัน (4/5/6 ธันวาคม) พร้อมเครื่องหมายถูกและทะเบียนรถของวันที่ซื้อ
- รองรับ KPI, filter, pagination, modal รูปภาพ, แก้ไขข้อมูล, PDF และ Export CSV

## การรัน

```bash
python3 -m http.server 8000
```
