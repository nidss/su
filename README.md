# Souped Up 2026 - ระบบสมัครการแข่งขัน / Competition Registration System

🔗 **Live:** https://nidss.github.io/su/


ระบบสมัครสมาชิกและลงทะเบียนการแข่งขันรถยนต์ **Souped Up 2026** โทนสีเข้มแนวแข่งรถ (มิ้นต์ `#6FFFE8` · เขียวมะนาว `#D1FF03` · กรมท่า `#0C142A`) รองรับ 2 ภาษา (ไทย/อังกฤษ, ค่าเริ่มต้น: ไทย) ทำงานแบบ **single-file** ไม่ต้อง build - ทุกภาพ/โลโก้/ฟอนต์ fallback ฝังอยู่ในไฟล์เดียว

A dark, racing-themed registration system for **Souped Up 2026**. Bilingual (TH/EN, default TH), single self-contained `index.html`, no build step.

## Public page
- **GitHub Pages** (favicon PNG ใช้งานได้): Settings → Pages → Deploy from branch `main` → root → `https://nidss.github.io/su/`
- ไฟล์หลักคือ `index.html` - เปิดในเบราว์เซอร์ได้ทันที ไม่มี dependency ที่ต้องติดตั้ง

## ขั้นตอนการลงทะเบียน / Registration flow (7 ขั้น)

การสมัครสมาชิกและกรอกข้อมูลส่วนตัว (รวมบัญชีคืนเงินมัดจำ) เป็น onboarding ก่อนเริ่มลงทะเบียน จึงไม่แสดงใน stepper ผู้สมัครเลือกได้ทั้ง **บุคคลธรรมดา** และ **นิติบุคคล** โดยฟอร์มนิติบุคคลรองรับชื่อบริษัท เลขผู้เสียภาษี สำนักงานใหญ่/สาขา ผู้ติดต่อ ที่อยู่จดทะเบียน และหนังสือรับรองบริษัท

1. **ข้อตกลงและเงื่อนไข** - อ่าน & ยอมรับเอกสาร 3 ฉบับ (นโยบายข้อมูล, กติกา, การค้ำประกันการแข่งขัน+ความเสียหาย) ผ่าน popup
2. **ข้อมูลนักแข่ง** - รถ/รหัสเครื่อง, รุ่นแข่ง, เบอร์รถ (1–120), อัปโหลดบัตร + รูปนักแข่ง
3. **ที่จอดรถ** - เลือกช่องพีทจาก**ผังงานจริง** (39 เต็นท์ × 4 ช่อง = 152 ช่อง) แบบจองที่นั่ง; เต็นท์แดง = ถูกจอง (sponsor), เหลือง = TENT AIR, มีเลนขับรถ, ปุ่ม expand ดูผังเต็มใน modal
4. **บัญชีรับเงินรางวัล**
5. **สรุปยอด** - ค่าสมัคร 7,000 + ค่ามัดจำ 10,000 = 17,000 ฿ + ช่องกรอกโค้ดส่วนลด
6. **ชำระเงิน** - บัตรเครดิต / QR-โอนเงิน + ออกใบกำกับภาษี + เงื่อนไขการชำระ
7. **สำเร็จ** - หมายเลขอ้างอิง + ใบเสร็จ

## ประวัติของฉัน / My Profile (เข้าจากการเข้าสู่ระบบ)
หลัง **เข้าสู่ระบบ** จะเข้าหน้าโปรไฟล์ (ซ่อน stepper) มี 3 เมนู:
- **ข้อมูลของฉัน** - ข้อมูลผู้สมัคร + รูปบัตร + แก้ไขได้ (ลบ/อัปโหลดรูปบัตร)
- **ข้อมูลนักแข่ง** - การ์ดนักแข่ง (มีได้มากกว่า 1) + ปุ่ม **เพิ่มนักแข่ง** (เริ่มจากข้อตกลงก่อนเข้าสู่ข้อมูลนักแข่ง)
- **ประวัติการลงทะเบียน** - ตารางประวัติการลงทะเบียนนักแข่ง

หลังผู้ใช้ใหม่กรอกข้อมูลส่วนตัวเสร็จ หน้าเลือกรายการจะพาปุ่ม **ลงทะเบียนนักแข่ง** เข้าหน้าข้อตกลงก่อนเริ่ม wizard ส่วนปุ่ม **ซื้อบัตร VIP Village** จะไปยัง `https://nidss.github.io/suvip/`

## Dashboard ผู้ดูแล / Admin dashboard
- เปิดด้วยคีย์ลัด **`Ctrl + Shift + Z`** → หน้า **เข้าสู่ระบบแอดมิน** ก่อน แล้วจึงเข้า Dashboard
- **KPI**: จำนวนคนลงทะเบียน · จำนวนนักแข่ง · ยอดเงินที่ชำระแล้ว
- **ตาราง 2 แท็บ** (ผู้สมัคร / นักแข่ง) - 20 แถว/หน้า + paging + **Export CSV**
- ดูรูปบัตร/รูปนักแข่งใน modal, แก้ไขข้อมูลแต่ละแถวได้ (รวมลบ/อัปโหลดรูป)

## หมายเหตุ / Notes
- เป็น **front-end demo** - auth/ชำระเงินเป็น mock, ข้อมูลใน Dashboard/โปรไฟล์เป็นข้อมูลตัวอย่างที่สุ่มขึ้น (ไม่มี backend)
- หน้าเข้าสู่ระบบมีบัญชีตัวอย่าง 2 แบบให้เลือก: **ผู้ใช้ใหม่** จะเริ่มกรอกข้อมูลส่วนตัว และ **ผู้ใช้เดิม** จะมีข้อมูลส่วนตัว นักแข่ง และ VIP พร้อมแล้ว (รหัสผ่านถูกเติมให้อัตโนมัติเมื่อเลือกบัญชี)
- บัญชี **ผู้ใช้เดิม** ใช้ข้อมูลตัวอย่างนิติบุคคลและบัญชีคืนเงินมัดจำที่กรอกครบ ในขั้นตอนข้อมูลนักแข่ง การ์ดนักแข่งแต่ละคนมี dropdown ให้เลือกแยกกันว่าจะส่งในนามบุคคลธรรมดาหรือนิติบุคคล
- โค้ดส่วนลดตัวอย่าง: `SOUPEDUP`, `EARLYBIRD`, `VIP2026`
- Export CSV ดาวน์โหลดได้จริงเมื่อเปิดผ่าน GitHub Pages/ไฟล์ในเครื่อง (บนหน้า Artifact การดาวน์โหลดถูก sandbox บล็อก)
