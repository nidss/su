# Souped Up 2026

ระบบเดโมสำหรับสมัครสมาชิก ลงทะเบียนนักแข่ง และซื้อบัตร **Souped Up VIP Village 2026** รองรับภาษาไทย/อังกฤษ ทำงานด้วย HTML, CSS และ JavaScript โดยไม่ต้อง build

- **Live:** https://nidss.github.io/su/
- **VIP standalone:** https://nidss.github.io/suvip/

> Auth, payment, profile และ Dashboard เป็น mock data สำหรับสาธิต ไม่มี backend หรือการชำระเงินจริง

## Flow หลัก

หน้าเข้าสู่ระบบมีบัญชีตัวอย่าง 2 แบบ:

- **ผู้ใช้ใหม่** — ยังไม่มีข้อมูลส่วนตัว นักแข่ง หรือ VIP
- **ผู้ใช้เดิม** — มีข้อมูลบุคคล/นิติบุคคล บัญชีคืนเงิน นักแข่ง และ VIP พร้อมแล้ว

หน้าแรกมีแบนเนอร์ **VIP Village** (รูป `ticket.png`) ใต้กล่องต้อนรับ กดแล้วเปิดหน้า https://nidss.github.io/suvip/ ในแท็บใหม่

หลังสมัครหรือเข้าสู่ระบบด้วยบัญชีที่ยังไม่มีข้อมูล ระบบจะ **เข้าสู่การลงทะเบียนนักแข่งโดยตรง** → กรอกข้อมูลส่วนตัวและบัญชีคืนเงินมัดจำ → ข้อตกลง → wizard นักแข่ง

> หน้า **คุณต้องการทำอะไร?** (เลือกนักแข่ง/VIP) ถูกซ่อนไว้ผ่าน flag `CHOOSE_ENABLED=false` — โค้ดยังอยู่ครบ เผื่อเปิดกลับมาในอนาคต

## ลงทะเบียนนักแข่ง

Stepper ไม่มีเลขนำหน้าและประกอบด้วย 7 ขั้น:

1. ข้อตกลง
2. นักแข่ง
3. ที่จอดรถ
4. บัญชีรับเงินรางวัล
5. สรุปยอด
6. ชำระเงิน
7. สำเร็จ

ฟอร์มปัจจุบันลงทะเบียนนักแข่ง 1 คนและ 1 รุ่นการแข่งขัน ปุ่มเพิ่มนักแข่ง/เพิ่มรุ่นถูกซ่อน บัญชีผู้ใช้เดิมสามารถเลือกประเภทผู้สมัครเป็นบุคคลธรรมดาหรือนิติบุคคลภายในข้อมูลนักแข่งแต่ละคน

ในขั้น **ที่จอดรถ** ช่องที่จองแล้ว (รวมช่อง mock 70–71) กดดูข้อมูลนักแข่งที่จองได้ **รายช่อง** ส่วนหน้า **บัญชีรับเงินรางวัล** ชื่อ/นามสกุลดึงจากข้อมูลส่วนตัวและแก้ไขไม่ได้ (ตัด checkbox บันทึกบัญชีออกแล้ว)

Pricing: ค่าสมัคร 7,000 บาท + ค่ามัดจำ 10,000 บาท = **17,000 บาทต่อคัน**

## ซื้อบัตร VIP Village

หน้า `vip.html` ใช้ UI จากโปรเจกต์ `suvip` และไม่มีส่วนข้อมูลผู้สมัคร

- เลือก Early Bird หรือ Normal Price
- วันเข้างาน 4–6 ธันวาคม 2026
- แพ็กเกจ 3 วันเลือกไม่ได้เมื่อมีวันที่เต็ม
- เลือกมีรถ/ไม่มีรถ; ถ้ามีรถต้องกรอกทะเบียน
- เลือกไซส์เสื้อและข้อมูลอาหารบุฟเฟต์แยกต่อบัตร
- กด **+ เพิ่มบัตรเข้างาน** เพื่อสร้างบัตรใบที่ 2 เป็นต้นไป
- กล่องบัตร collapse/expand ได้เมื่อมีหลายใบ
- รองรับหน้าชำระเงิน ใบกำกับภาษี และใบเสร็จเดโม

หน้าซื้อบัตรเวอร์ชัน standalone ถูก sync ไปที่ [nidss/suvip](https://github.com/nidss/suvip)

## ข้อมูลส่วนตัวและประวัติ

- รองรับบุคคลธรรมดาและนิติบุคคล
- Line เป็นข้อมูลบังคับ
- ไม่มีวัน/เดือน/ปีเกิดและที่อยู่จัดส่ง
- บัญชีคืนเงินมัดจำอยู่ในข้อมูลส่วนตัวและไม่แสดงสำหรับเส้นทาง VIP
- ประวัติการลงทะเบียนและ VIP Village เปิดใบเสร็จผ่าน modal ได้

## Dashboard ผู้ดูแล

เปิดด้วย `Ctrl + Shift + Z`

- กลุ่ม **ข้อมูลผู้สมัคร, นักแข่ง** และ **ข้อมูลผู้ซื้อบัตร VIP Village**
- ผู้สมัครใช้คอลัมน์ `วันที่ลงทะเบียน`
- นักแข่งมี `วันที่ลงทะเบียน`, `วันที่ชำระเงิน` และ `Status` การจ่ายเงิน
- ตารางผู้ซื้อ VIP มีคอลัมน์ `ชื่อ`, `นามสกุล`, `วันที่ชำระเงิน` และ `สถานะ` การชำระเงิน (ตัดคอลัมน์ `ชื่อผู้ใช้` ออก) พร้อมแถบค้นหาแยกฟิลด์ตาม criteria เหนือตาราง
- รองรับ KPI, filter, pagination, modal รูปภาพ, แก้ไขข้อมูล, PDF และ Export CSV

## การรัน

เปิด `index.html` ได้โดยตรง หรือใช้ local server:

```bash
python3 -m http.server 8000
```

จากนั้นเปิด `http://localhost:8000/`

## Deploy

GitHub Pages deploy จาก branch `main` ที่ root ไปยัง https://nidss.github.io/su/

ทุกครั้งที่แก้ `index.html` ต้อง regenerate `souped-up.html` และ commit พร้อมกัน
