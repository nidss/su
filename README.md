# Souped Up 2026 — ระบบสมัครการแข่งขัน / Competition Registration System

URL: https://nidss.github.io/su/


ระบบสมัครสมาชิกและลงทะเบียนการแข่งขันรถยนต์ **Souped Up 2026** โทนสีเข้มแนวแข่งรถ (มิ้นต์ `#6FFFE8` · เขียวมะนาว `#D1FF03` · กรมท่า `#0C142A`) รองรับ 2 ภาษา (ไทย/อังกฤษ, ค่าเริ่มต้น: ไทย) ทำงานแบบ **single-file** ไม่ต้อง build — ทุกภาพ/โลโก้/ฟอนต์ fallback ฝังอยู่ในไฟล์เดียว

A dark, racing-themed registration system for **Souped Up 2026**. Bilingual (TH/EN, default TH), single self-contained `index.html`, no build step.

## Public page
- **GitHub Pages** (favicon PNG ใช้งานได้): Settings → Pages → Deploy from branch `main` → root → `https://nidss.github.io/su/`
- ไฟล์หลักคือ `index.html` — เปิดในเบราว์เซอร์ได้ทันที ไม่มี dependency ที่ต้องติดตั้ง

## ขั้นตอนการลงทะเบียน / Registration flow (9 ขั้น)
1. **สมาชิก** — สมัครสมาชิก / เข้าสู่ระบบ (แบบ Tab)
2. **ข้อตกลงและเงื่อนไข** — อ่าน & ยอมรับเอกสาร 3 ฉบับ (นโยบายข้อมูล, กติกา, การค้ำประกันการแข่งขัน+ความเสียหาย) ผ่าน popup
3. **ข้อมูลผู้สมัคร** — วันเกิด, ที่อยู่ตามบัตร/จัดส่ง, ช่องทางติดต่อ (Line/WeChat/WhatsApp), อัปโหลดบัตรประชาชน
4. **ข้อมูลนักแข่ง** — รถ/รหัสเครื่อง, รุ่นแข่ง, เบอร์รถ (1–120), อัปโหลดบัตร + รูปนักแข่ง
5. **ที่จอดรถ** — เลือกช่องพีทจาก**ผังงานจริง** (39 เต็นท์ × 4 ช่อง = 152 ช่อง) แบบจองที่นั่ง; เต็นท์แดง = ถูกจอง (sponsor), เหลือง = TENT AIR, มีเลนขับรถ, ปุ่ม expand ดูผังเต็มใน modal
6. **บัญชีคืนเงิน / รับเงินรางวัล**
7. **สรุปยอด** — ค่าสมัคร 7,000 + ค่ามัดจำ 10,000 = 17,000 ฿ + ช่องกรอกโค้ดส่วนลด
8. **ชำระเงิน** — บัตรเครดิต / QR-โอนเงิน + ออกใบกำกับภาษี + เงื่อนไขการชำระ
9. **สำเร็จ** — หมายเลขอ้างอิง + ใบเสร็จ

## ประวัติของฉัน / My Profile (เข้าจากการเข้าสู่ระบบ)
หลัง **เข้าสู่ระบบ** จะเข้าหน้าโปรไฟล์ (ซ่อน stepper) มี 3 เมนู:
- **ข้อมูลของฉัน** — ข้อมูลผู้สมัคร + รูปบัตร + แก้ไขได้ (ลบ/อัปโหลดรูปบัตร)
- **ข้อมูลนักแข่ง** — การ์ดนักแข่ง (มีได้มากกว่า 1) + ปุ่ม **เพิ่มนักแข่ง** (ข้ามไปขั้นตอน 04 ทันที)
- **ประวัติการลงทะเบียน** — ตารางประวัติการลงทะเบียนนักแข่ง

## Dashboard ผู้ดูแล / Admin dashboard
- เปิดด้วยคีย์ลัด **`Ctrl + Shift + Z`** → หน้า **เข้าสู่ระบบแอดมิน** ก่อน แล้วจึงเข้า Dashboard
- **KPI**: จำนวนคนลงทะเบียน · จำนวนนักแข่ง · ยอดเงินที่ชำระแล้ว
- **ตาราง 2 แท็บ** (ผู้สมัคร / นักแข่ง) — 20 แถว/หน้า + paging + **Export CSV**
- ดูรูปบัตร/รูปนักแข่งใน modal, แก้ไขข้อมูลแต่ละแถวได้ (รวมลบ/อัปโหลดรูป)
